One original dad joke, one line:

> I tried to fix the leaky tap with duct tape and confidence. The tap is now leaking confidence.

The twist lands on the very last word: "confidence" starts as the dad's second tool and ends as the thing leaking. The dad's DIY fix fails — he is the loser here, beaten by his own tap — and nothing is explained; the reader does the last step.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the fixed line to `/output/entry.txt` (94 code points, inside the 1–140 gate). Node 22 standard library only, fully deterministic: same bytes on every run — no clock, no randomness, no network.
